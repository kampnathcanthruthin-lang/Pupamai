# เช็คชื่อหน้าเสาธง ม.6/8 (เก็บข้อมูลใน Google Sheets)

เว็บเช็คชื่อ (มา / สาย / ขาด / ลา) ข้อมูลทั้งหมดถูกบันทึกในกูเกิลชีตของคุณ เปิดดูและแก้ไขได้ตลอด
นักเรียนที่ **สาย + ขาด รวมครบ 2 ครั้ง** จะขึ้นสีแดงและแจ้งเตือนว่าเสี่ยงโดนหักคะแนน

## โครงสร้างไฟล์

```
index.html                    หน้าเว็บ
api/_lib.js                   ตัวช่วยเชื่อม Google Sheets + ตรวจรหัสครู
api/students.js               API รายชื่อนักเรียน
api/attendance.js             API เช็คชื่อและสรุป
google-apps-script/Code.gs    โค้ดที่วางใน Google Sheets (ทำหน้าที่เป็นฐานข้อมูล)
package.json
```

## ขั้นตอนติดตั้ง

### ส่วนที่ 1: ตั้งค่า Google Sheets
1. สร้างกูเกิลชีตใหม่ ตั้งชื่ออะไรก็ได้ เช่น "เช็คชื่อ ม.6/8"
2. เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดเดิมทิ้ง แล้ววางโค้ดจาก `google-apps-script/Code.gs`
4. แก้บรรทัด `const SECRET = '...'` เป็นรหัสลับที่คุณตั้งเอง (จดไว้ ใช้ในขั้นตอนถัดไป)
5. กด **Deploy (การทำให้ใช้งานได้) > New deployment (การทำให้ใช้งานได้รายการใหม่)**
   - เลือกประเภท **Web app**
   - Execute as (เรียกใช้ในฐานะ): **Me (ฉัน)**
   - Who has access (ผู้ที่มีสิทธิ์เข้าถึง): **Anyone (ทุกคน)**
6. กด Deploy แล้วอนุญาตสิทธิ์ตามที่ Google ถาม (ถ้าขึ้นว่า "Google hasn't verified this app" ให้กด Advanced > Go to ... ได้เลย เพราะเป็นสคริปต์ของคุณเอง)
7. คัดลอก **Web app URL** (ขึ้นต้นด้วย `https://script.google.com/macros/s/...`)

### ส่วนที่ 2: เผยแพร่เว็บ
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub
2. ที่ https://vercel.com เลือก **Add New > Project** แล้วเลือก repo นี้ ก่อนกด Deploy ใส่ **Environment Variables** 3 ตัว:
   - `SHEETS_URL` = Web app URL จากข้อ 7
   - `SHEETS_SECRET` = รหัสลับเดียวกับ `SECRET` ใน Apps Script
   - `ADMIN_PIN` = รหัสผ่านที่ครูใช้เข้าเว็บ
3. กด Deploy แล้วเปิดเว็บ กรอกรหัส เข้าแท็บ "จัดการรายชื่อ" วางรายชื่อ ม.6/8 แล้วเริ่มเช็คชื่อได้เลย

## ดูข้อมูลในกูเกิลชีต

ชีตจะสร้างแท็บให้เองอัตโนมัติ:
- `attendance` : บันทึกทุกครั้ง (วันที่, เลขที่, ชื่อ, สถานะ มา/สาย/ขาด/ลา)
- `สรุป` : จำนวนมา สาย ขาด ลา ของแต่ละคน แถวที่สาย+ขาดครบเกณฑ์เป็นสีแดง พร้อมคำว่า "เสี่ยงโดนหักคะแนน"
- `students` : รายชื่อนักเรียน

## หมายเหตุ

- แก้ข้อมูลในแท็บ `attendance` ตรงๆ ได้ แต่ให้คงรูปแบบวันที่ `YYYY-MM-DD` และสถานะเป็น มา/สาย/ขาด/ลา ส่วนแท็บ `สรุป` ระบบเขียนทับให้ทุกครั้งที่บันทึกในเว็บ อย่าแก้ตรงนั้น
- ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้อง Deploy เวอร์ชันใหม่ (Manage deployments > Edit > New version) ถึงจะมีผล
- ปรับเกณฑ์เตือน: แก้ `THRESHOLD` ทั้งใน `index.html` และ `Code.gs`
